# Themis — Production Deployment Guide

A complete blueprint for deploying **Themis** to production on **Vercel** with **Neon**, **Pinecone**, **Inngest Cloud**, and **GitHub App**.

---

## 1. System Architecture

- **Next.js 16 (App Router)**: Frontend dashboard, landing page, and backend API routes.
- **Neon PostgreSQL + Prisma ORM**: Cloud database for users, sessions, GitHub installations, PR tracking, and sync states.
- **Pinecone Vector Database (Documents API)**: Storage for embeddings generated by `llama-text-embed-v2` for repo codebase & PR diff context.
- **OpenRouter AI**: Multi-dimensional code review generation using high-quality LLMs.
- **Inngest Cloud**: Background event-driven workflow engine for async PR reviews and codebase chunking.
- **GitHub App**: Direct webhook integration and automated review comments via Octokit bot authentication.

## 3. Step-by-Step Deployment Steps

### Step 1: Inngest Cloud Setup (Free)
1. Sign up / login at [Inngest Cloud](https://app.inngest.com/).
2. Create an environment (e.g. `Production`).
3. Under **Manage -> Keys**, copy:
   - **Event Key** (`INNGEST_EVENT_KEY`)
   - **Signing Key** (`INNGEST_SIGNING_KEY`)

### Step 2: Deploy to Vercel
1. Go to [Vercel](https://vercel.com/new) and import your repo: `https://github.com/Jadeja-Karmadeepsinh/Themis.git`.
2. Add all environment variables listed above.
3. Click **Deploy**.
4. Once deployed, copy your assigned domain: `https://<your-project>.vercel.app`.

### Step 3: Update GitHub App Settings
Open [GitHub Developer Settings -> themis-jadeja-karmadeepsinh](https://github.com/settings/apps/themis-jadeja-karmadeepsinh):

- **Homepage URL**: `https://<your-project>.vercel.app`
- **User authorization callback URL**:
  - `https://<your-project>.vercel.app/api/github/callback`
  - `https://<your-project>.vercel.app/api/auth/callback/github`
- **Setup URL (Post installation)**: `https://<your-project>.vercel.app/api/github/callback`
- **Redirect on update**: Checked (Yes)
- **Webhook URL**: `https://<your-project>.vercel.app/api/github/webhook` *(Smee is NOT needed in production!)*
- **Webhook Secret**: Must match `GITHUB_WEBHOOK_SECRET`

### Step 4: Sync Inngest
In the Inngest Cloud Dashboard, navigate to **Apps** -> **Sync New App** and provide:
`https://<your-project>.vercel.app/api/inngest`

All 3 background functions will register immediately.
